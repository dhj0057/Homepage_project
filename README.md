# Healthcare Dashboard

데이터 기반 건강 관리 플랫폼 프로젝트입니다.

식단, 운동, 건강 데이터를 단순 기록이 아닌  
구체적이고 기계적인 수치 중심으로 관리할 수 있도록 설계되었습니다.

현재 버전은 HTML/CSS 기반 UI 프로토타입이며,  
향후 데이터베이스 및 백엔드 기능이 추가될 예정입니다.

---

# 프로젝트 목표

많은 사람들이 정보 부족으로 인해 건강하지 않은 선택을 반복합니다.

이 프로젝트는:

- 식단 데이터 분석
- 운동 루틴 관리
- 건강 지표 기록
- 약물 및 영양제 관리

등을 통해 사용자가 더 명확하고 객관적인 기준으로  
건강을 관리할 수 있도록 지원하는 것을 목표로 합니다.

---

# 주요 기능

## 식단 관리
- 칼로리 추적
- 매크로 영양소 관리
- 식사 시간 기록
- 영양 데이터 기반 분석

## 운동 분석
- 운동 루틴 관리
- 인바디 기반 데이터 활용
- 약점 분석
- 운동 시간 및 활동량 추적

## 건강 관리
- 영양제 관리
- 약물 복용 기록
- 건강 수치 관리
- 데이터 기반 건강 모니터링

# 개발 목적

이 프로젝트는 개인 건강 관리 및 프론트엔드 학습을 목적으로 제작되었습니다.

단순 UI 제작이 아닌:

- 데이터 기반 사고
- 정보 접근성 향상
- 사용자 중심 건강 관리

를 핵심 방향성으로 개발 중입니다.
